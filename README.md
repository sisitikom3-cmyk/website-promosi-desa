# Website Promosi Desa - 5 Halaman

Website promosi desa yang modern dan responsif dengan 5 halaman utama.

## Fitur Utama

✨ **5 Halaman Lengkap:**
1. **Beranda (index.html)** - Halaman utama dengan hero section dan fitur unggulan
2. **Tentang Kami (tentang.html)** - Sejarah, visi, misi, dan tim
3. **Galeri (galeri.html)** - Foto dan video dengan filter kategori
4. **Produk (produk.html)** - Katalog produk dengan filter kategori
5. **Kontak (kontak.html)** - Formulir kontak, FAQ, dan informasi lokasi

## Teknologi yang Digunakan

- **HTML5** - Struktur halaman
- **CSS3** - Styling dan responsive design
- **JavaScript** - Interaktifitas dan dinamis

## Fitur Interaktif

✓ Menu navigasi responsif dengan hamburger menu
✓ Filter galeri berdasarkan kategori
✓ Filter produk berdasarkan kategori
✓ Formulir kontak yang fungsional
✓ Animasi scroll yang mulus
✓ Design mobile-friendly (responsif)
✓ Kartu produk dengan hover effects
✓ Social media links

## Cara Menggunakan

1. **Clone/Download repository**
   ```bash
   git clone https://github.com/sisitikom3-cmyk/website-promosi-desa.git
   cd website-promosi-desa
   ```

2. **Buka di browser**
   - Buka file `index.html` dengan browser pilihan Anda
   - Atau gunakan Live Server di VS Code

3. **Kustomisasi**
   - Edit konten di file HTML sesuai kebutuhan desa Anda
   - Ubah warna di file `css/style.css`
   - Modifikasi JavaScript di `js/script.js` sesuai kebutuhan

## Customization Guide

### Mengubah Nama Desa
Cari dan ganti "Desa Wisata Sejahtera" dengan nama desa Anda di semua file HTML.

### Mengubah Warna Tema
Edit variabel di `css/style.css`:
```css
:root {
    --primary-color: #2ecc71;      /* Ubah warna utama */
    --secondary-color: #27ae60;    /* Ubah warna sekunder */
}
```

### Menambah Konten
- Tambahkan produk baru di halaman produk
- Tambahkan foto di galeri
- Ubah informasi kontak sesuai data sebenarnya
